# Haskell Starter Kit

This is a collection of general functions, applications, and simple text based games
to help me learn the basics of Haskell

## General Functions

- Fizz-Buzz
- Fibonacci
- Factorial
- Bubble Sort
- Palindrome checker
- String Reversal
- Binary Search

## Simple CLI Applications

- Simple Chat Bot
- Simple Calculator
- To-Do List

## Simple CLI Games

- Guess the Random Number
- Rock Paper Scissors
- Deck of Cards
- Tic-Tac-Toe
