# Haskell Starter Kit

This is a collection of general operations and simple brain-teasers to help me
get a bit of a grasp on the Haskell Programming Language. I do quite like how 
type annotations work in Haskell, as well as error handing. I think this
project taught me so much. If I hadn't learned about them by using Haskell
I don't think I would have ever many of these higher order functions including
but not limited to: folds, take, drop, or zip. I truly think that learning
a little Haskell has made me a better programmer, and I can take the skills
with me to other languages.
